## Проверка перед сдачей
1. `python -m pytest tests -q` — все тесты зелёные.
2. `./scripts/start_server.sh` и `./scripts/start_tunnel.sh` запущены; адрес `https://…trycloudflare.com/api/v1/health` отвечает `{"status":"ok"}`.
3. Через публичный адрес: `curl -X POST …/api/v1/analyze -H "X-API-Key: …" -F "file=@video.mov"` → `job_id`; `GET …/api/v1/jobs/<job_id>` → `done` в пределах 5 минут.
4. Без ключа / с неверным ключом — `401`.
5. Компьютер не уходит в сон, питание подключено, сеть стабильна, пока жюри проверяет.
